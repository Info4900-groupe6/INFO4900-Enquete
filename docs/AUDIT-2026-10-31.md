# Audit des scènes — 31 octobre 2026

## Origine des changements

Le dépôt distant au commit `9e9c76a` contenait le modèle Unity initial, sans
CercleVR. Cette modification intègre les sources et ressources du projet local
audité : les deux scènes, dix scripts, matériaux utilisés, Starter Assets XR,
TextMesh Pro, réglages OpenXR/URP et dépendances verrouillées. Les scènes originales
et leurs GUID sont conservés. La scène SampleScene et les ressources initiales du
dépôt restent disponibles.

Les caches, builds, enregistrements, sauvegardes et paramètres personnels de
l'éditeur ne sont pas versionnés. Le connecteur utilisé pour l'audit reste
facultatif ; les manifestes antérieurs à son installation sont repris. La liaison
Unity Cloud locale n'est pas transférée au dépôt.

## Corrections appliquées

1. La liste globale de build référence les scènes réelles `CerclePC.unity` et
   `CercleQuest.unity`, avec leurs GUID d'origine. Le projet local référençait des
   chemins inexistants terminés par ` 3.unity`.
2. Le profil Meta Quest remplace la liste globale et inclut CercleQuest seule.
3. Le profil Cercle PC inclut CerclePC seule pour Windows Player.
4. Le générateur réutilise `Sol.mat` et le crée uniquement s'il est absent.
   La génération de scènes conserve des chemins uniques pour préserver les originaux.
5. Les tests Core de l'audit sont inclus avec des chemins relatifs au dépôt.
   Le message du générateur renvoie désormais au README existant.
6. L'image initiale `Assets/TutorialInfo/Icons/URP.png`, stockée en brut malgré sa
   règle Git LFS, est normalisée en pointeur LFS ; son contenu reste identique.

## Doublons

Les seuls fichiers retirés du projet local sont `Sol 1.mat` à `Sol 5.mat`, avec
leurs cinq `.meta`. Aucune référence GUID ni dépendance directe AssetDatabase
n'a été trouvée avant suppression. Après normalisation du nom et de l'identifiant
local du sous-objet URP, Sol 1/2 équivalent à Sol et Sol 3/4/5 à Sol 6.

Ces doublons n'existaient pas dans le commit distant initial : ils sont donc
exclus de l'import, pas présentés comme des suppressions Git. `Sol.mat`, `Sol 6.mat`
(PC) et `Sol 7.mat` (Quest) sont conservés. Les originaux supprimés et leurs `.meta`
ont été sauvegardés hors du projet avant le nettoyage. Aucun autre matériau,
script, scène originale ou exemple XR n'a été supprimé.

- Compilation C# réussie après correction du générateur.
- Parcours statique : 86 dépendances atteintes, aucun GUID manquant ou actif en double.
- Inspection Unity : PC 5 GameObjects, Quest 67 ; aucun script manquant ni référence
  sérialisée cassée. Dépendances AssetDatabase : 7 pour PC, 96 pour Quest, scène incluse.
- Unity Test Runner : aucun test déclaré. Harnais Core : 732 assertions réussies,
  24 énigmes, 4 campagnes complètes.
- Play PC : 7 PNJ, 36 actions, progression du niveau 1 au niveau 2 confirmée.
- Play Quest : XR actif, 6 niveaux validés, transitions et ouverture finale confirmées.
  Les captures de rendu ont été inspectées. Le XR peut provenir du simulateur.
- Windows Mono : build réussi, 0 erreur / 4 avertissements ; démarrage du programme
  vérifié sans exception. Cette validation avait PC en premier et les deux scènes
  globales incluses à cause du comportement du connecteur. Elle ne valide pas un
  build final PC à scène unique. Le backend IL2CPP d'origine a ensuite été restauré.

Les avertissements concernent notamment des shaders URP, une ancienne directive

Les paquets fournisseurs n'ont pas été modifiés pour masquer ces avertissements.

de jeu associé. L'initialisation XR Standalone d'origine est conservée.
